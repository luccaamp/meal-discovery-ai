# Modelos

Nenhum modelo treinado ou publicado. Guardar artefatos localmente, com versão dos dados/código, parâmetros, métricas e limitações. Antes de publicar no Hugging Face, verificar termos, inferência reproduzível e risco de expor IDs/históricos em artefatos colaborativos. Se necessário publicar somente um componente que possa ser distribuído adequadamente.
