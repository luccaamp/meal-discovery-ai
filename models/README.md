# Modelos

Popularidade, repetição e similaridade por cesta foram ajustadas em memória no treino real de Singapura e avaliadas sobre 109.842 usuários de validação. [Experimento e resultados](../docs/EXPERIMENT_001.md). O teste dos dias 69–75 não foi avaliado. São referências estatísticas de recomendação, sem LLM treinado ou modelo neural nesta etapa.

Nenhum modelo foi persistido ou publicado no Hugging Face. Para reproduzir, executar o protocolo com os dados locais e versões documentadas. Artefatos futuros deverão registrar dados/código, parâmetros, métricas e limitações. Antes de publicar um modelo colaborativo, verificar condições dos dados e possibilidade de expor IDs/históricos; selecionar um componente distribuível adequadamente.
