# Modelos

Referências de popularidade, repetição e similaridade entre itens são ajustadas em memória durante o benchmark. Só foram verificadas com exemplos sintéticos; nenhum modelo foi treinado em DHRD, persistido ou publicado. Guardar artefatos localmente, com versão dos dados/código, parâmetros, métricas e limitações. Antes de publicar no Hugging Face, verificar termos, inferência reproduzível e risco de expor IDs/históricos em artefatos colaborativos. Se necessário publicar somente um componente que possa ser distribuído adequadamente.
